Vana'diel Weather Clock

How to run on Windows 11:
1. Extract this folder.
2. Double-click "Install VanaDiel Widget.bat" to add Desktop and Start Menu shortcuts.
3. Choose Y if you want it to start automatically when Windows starts.
4. Launch it from the Desktop shortcut or "Start VanaDiel Widget.bat".

Quick run without installing shortcuts:
- Double-click "Start VanaDiel Widget.bat" or "Launch Vana'diel Clock.bat".

What it includes:
- Final Fantasy XI-inspired Windows 11 glass widget design.
- Vana'diel time and date conversion.
- Vana'diel game day, current element, and moon phase.
- Settings gear with ZIP code input for Earth time and time zone display.
- Zone selector with simulated FFXI-style weather.
- Weather search for finding locations with selected weather now or in the next 32 minutes.
- Full location dropdown sourced from the FFXI zone list.
- Original FFXI-inspired fantasy background art that randomizes every 2 minutes.
- Compact mode for a smaller desktop clock.
- Windows widget-style launcher using Microsoft Edge or Chrome app mode.

Note:
The clock uses fan-calculated Vana'diel time. Weather is a themed forecast simulator, not a live feed from Square Enix servers. Backgrounds are original fantasy artwork inspired by the mood of classic MMORPG zones, not official Square Enix art.
